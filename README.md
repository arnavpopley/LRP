## Objectives (agreed 12 Oct)

1. Outline the atmospheric chemistry by which H₂ acts as an indirect greenhouse gas.
2. Evaluate how its GWP has been estimated (metric, model type, assumptions).
3. Compare published estimates and explain the spread over time.
4. Engineering view of deployment: leakage vs break-even, infrastructure (porosity), detection (odorants, sensors), and net result.
